# مرتّبات أطقم السفن — دليل التشغيل

الشاشة: `/dashboard/fleet-crew-salaries`
الواجهة البرمجيّة: `api/crew-salaries`
الوحدة: `src/modules/crew-salaries`

## ترتيب النشر (المخطَّط لا يتغيّر تلقائيّاً في الإنتاج)

1. نسخة احتياطيّة من القاعدة.
2. الهجرة:

```
node scripts/run-migration.js docs/crew-salaries-up.sql
```

3. التحقّق: رسالة «الجداول العشرة موجودة».
4. نشر الباك، ثمّ نشر الفرونت.

التراجع:

```
docs/crew-salaries-down.sql
```

البوّابة ترفض الحذف إن وُجد أيّ صفّ، إلّا بقرارٍ صريح:

```
SET LOCAL crew_salary.force_drop = 'yes';
```

## صاحب صلاحية الاعتماد

متغيّر بيئة واحد على Railway:

```
CREW_SALARY_APPROVER_USER_ID=8712bd6f-1880-4fd7-9a7d-8e9976e88eb1
```

أكّد المالك في ٢٧ سبتمبر ٢٠٢٦ أنّ هذا حسابه، وأنّه صاحب الصلاحية الوحيد:

```
mohamed@ume.com
```

والمتغيّر يُضبط على Railway عند النشر، لا قبله.

- غيابه أو فساده = **لا معتمد**: كلّ اعتمادٍ مرفوض.
- لا يُمنح لكلّ أدمن، ولا يُعدَّل من الواجهة.
- الاعتماد يشمل إصدارات المرتّبات وحسابات الصرف وتفويضات المستفيد.

## أسعار الصرف

من جدول `exchange_rates` القائم، لشهر الدورة نفسه فقط. لا يُستعمل صفّ `default` ولا أيّ قيمةٍ مضمَّنة.
الإدخال بصيغة «١ EUR = X USD» ويُخزَّن بصيغة الجدول (وحداتٌ لكلّ دولار).
والإصدار المعتمد يحفظ لقطة السعر فلا يتأثّر بتعديله لاحقاً.

## الاختبارات

وحدات خالصة ومحلّلات:

```
npx jest src/modules/crew-salaries
```

الهجرة وسير العمل على PostgreSQL مؤقّتة محلّيّة (لا اتّصال بالإنتاج):

```
npm run test:pg
```

- العنقود المؤقّت خارج الريبو في مجلّد النظام المؤقّت، والتهيئة الأولى ~٩٠ ثانية.
- كلّ ملفّ اختبار ينشئ قاعدته بترميز UTF8 ويحذفها.

عيّنة حقيقيّة (لا تدخل Git أبداً):

```
CREW_SAMPLE_DIR=<مجلّد فيه aug.msg و cfm_usd.xlsx و cfm_eur.xlsx> npx jest crew-salary.sample
CREW_SAMPLE_DIR=<المجلّد نفسه> npm run test:pg -- crew-salaries.sample
```

## حدود هذه المرحلة

- لا إرسال تحويلات، ولا تأكيد سداد، ولا قيود محاسبيّة. «صُدِّر» ليست «سُدِّد».
- كشف الصرف Excel عامّ، لا يُسمّى «جاهزاً للبنك». قالب كلّ بنك يُضاف لاحقاً.
- نصّ ملفّات PDF لا يُستخرج: تُحفظ دليلاً، والبيانات من نظيرها xlsx أو يدويّاً.
- ورقة نشاط اللاشينج لا تُقرأ (مبالغها من نصّ الرسالة).
