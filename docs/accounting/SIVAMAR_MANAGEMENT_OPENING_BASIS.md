# SIVAMAR — MANAGEMENT OPENING BASIS · P1.4A

**أساس القبول تغيّر من `AUDITOR-SUPPORTED` إلى `MANAGEMENT-APPROVED`.**

هذا **لا يعني أن الأرصدة مدقَّقة.** يعني أن غياب الدليل الخارجي لم يعد حاجزاً
تقنياً — وأنه يبقى **ظاهراً ومُعلَناً في كل سطر**.

`journal_entries = 0` · `journal_lines = 0` — لم يُرحَّل شيء، ولن يُرحَّل في P1.4A.

## القاعدة غير القابلة للتفاوض

**لن يُكتب في أي مكان — نظاماً أو وثيقةً — أن رصيداً:**


**ما لم يوجد دليل فعلي.** ولا يوجد اليوم دليل خارجي لأي سطر.

## قاعدة الدفتر المساعد — بلا اختلاق

الحسابان `1100` و`2010` مُعلَّمان `requires_subledger = true` في الدليل المُحمَّل.
**لن يُختلَق سطر عميل أو مورّد واحد.** الافتتاح على مستوى المراقبة فقط.

**«إعادة بناء الدفتر المساعد مطلوبة»** حالة مسجَّلة **في هذا السجلّ** — ولم أُضِف
عموداً للمخطط. `requires_subledger` القائم يكفي للإشارة إلى الحاجة، وإضافة عمود
`requires_subledger_reconstruction` تغيير مخطط لا يشتريه شيء اليوم. لو أردته حقلاً
في قاعدة البيانات فهو **قرار مخطط منفصل** يُعرض ويُعتمد أولاً.

**النظام لن يتظاهر بوجود دفتر مساعد افتتاحي.** لا صفوف ولا أسماء ولا مراجع.

# 6 · سياسة التعديل المستقبلي

## القيد الافتتاحي ثابت — والثبات مفروض بالمحرّك لا بالسياسة

بعد الترحيل **لا يُعدَّل ولا يُحذف**. هذا ليس التزاماً إجرائياً — الدفاع مبنيّ في
قاعدة البيانات:

```
trg_je_immutable          يقارن الصف كاملاً كـjsonb — أي تعديل مرفوض
trg_jl_immutable          أسطر المُرحَّل لا تُمسّ
trg_je_balanced_deferred  التوازن يُفحص عند COMMIT
REVOKE + RLS              لا وصول مباشر يلتفّ على ما سبق
```

مُثبَت عملياً بـ87 فحصاً على PostgreSQL حقيقي.

## عند توفّر مستندات أو تعديلات مدقّق

**قيد تسوية افتتاح جديد** — مؤرَّخ ومستقل:

| الحقل | القيمة |
|---|---|
| نوع الحدث | `adjustment` |
| الدفتر | `OJ` |
| تاريخ الأثر | تاريخ الاعتماد لا 01/01/2026 |
| `reference` | رقم القيد الافتتاحي الأصلي |
| `source_document_date` | تاريخ المستند الجديد |
| الوصف | السبب ومصدر التعديل |
| الاعتماد | معتمِد التعديل وتاريخه |

```
القيد الافتتاحي الأصلي  →  يبقى كما هو إلى الأبد
قيد التسوية             →  يحمل الفرق ومبرّره
الأثر الصافي            →  صحيح
أثر التدقيق             →  كامل ومقروء
```

**ما لن يحدث:** إعادة كتابة · تعديل مبلغ · حذف سطر · «تصحيح» صامت.
